Excel with AI

Formulas written for you, messy data cleaned up, and every one of them tested on a single row first.

Why this matters

Suresh gives up on VLOOKUP again

Suresh schedules maintenance for a Coimbatore plant. He needs to match 600 machine codes against a service history sheet. He knows what he wants. He has never got VLOOKUP to work, so he does it by hand every quarter.

Two days a quarter, matching rows by eye.
What changes

Describe the match in plain English. Test it on one row.

What you'll be able to do

By the end of this module

  • 1Describe what you want and get a working formula back

  • 3Fix a formula error without understanding the error message
  • 4Clean messy data without retyping a single cell

Describe, do not remember

Plain English to formula

Describe it in plain English

You do not need to remember the syntax. You need to describe the job precisely.

1

Name the columns

"Machine code is in column A, dates in column D."

2

Say what you want

"Find the last service date for each code."

3

Say what if missing

"Show 'no record' rather than an error."

4

Ask for one formula

"Give me the formula only, no explanation."

The formula prompt

Copy this prompt
I have machine codes in column A of Sheet1, and a service history in Sheet2 with codes in column A and dates in column D. In Sheet1 column B I want the most recent service date for each code, and the words "no record" if there is no match. Give me the formula only, for Excel, with no explanation.
Columns, sheets, what you want, what if missing.
Why this works
  • Naming sheets and columns removes all the guesswork.
  • Saying what to show when there is no match avoids #N/A everywhere.
  • "Formula only" saves you scrolling past three paragraphs.
The one-row test

Before you fill down

Test it on one row first

  1. Paste the formula into a single cell, not the whole column.
  2. Pick a row where you already know the correct answer.
  3. Check the result matches what you know, exactly.
  4. Only then fill it down the column.
Copy this prompt
The formula you gave me returns 14 March for machine code M-2201, but the service sheet shows 2 April for that code. Tell me what is wrong with the formula and give me a corrected version. Formula only.
Naming a row you know the answer for is the whole technique.

Why the one-row test matters

Filled straight down
  • The formula looks right and produces 600 dates.
  • It has matched on the wrong column, so 600 dates are plausible and wrong.
  • The maintenance schedule is built on them before anyone notices.
One row first
  • You test it on M-2201, where you know the answer is 2 April.
  • It returns 14 March, so you catch it in ten seconds.
  • One correction, then 600 correct dates.

A wrong formula does not error. It produces six hundred confident, wrong answers.

Fixing errors

Paste the message, not the sheet

Paste the error, not the sheet

Safe to paste

About the structure

  • The formula itself
  • The error message: #N/A, #REF!, #VALUE!
  • Column letters and what each holds
  • One made-up example row
Never paste

The actual data

  • Customer names against values
  • Employee names, salaries or attendance
  • Real account or invoice numbers
  • The whole sheet, "so it has context"

Terms on this page: Personal data

The error-fixing prompt

Copy this error prompt
This formula returns #N/A: [paste the formula]. Column A holds machine codes like M-2201 as text. Column D holds dates. Tell me the two most likely causes and give me a corrected formula for each. Formulas only, one line of explanation each.
Describe what the columns hold. Never paste what is in them.
What comes back
  • Two likely causes, usually including a text-versus-number mismatch.
  • A corrected formula for each, ready to test on one row.
  • No data left your laptop, because you described it instead.
Cleaning messy data

Without retyping

Cleaning without retyping

Ask for the steps, not the result

For cleaning, the instructions are more useful than an answer, because you keep control of the sheet.

Ask for the method

"Give me the Excel steps to split this column" beats pasting the column in.

Ask for a formula

A formula you paste in works on all 600 rows and leaves the data where it is.

Test on one row

Same rule as always. One known answer before you fill anything down.

Do this now

Solve one real Excel problem

Do this now: solve one problem

  1. Think of the Excel job you currently do by hand.
  2. Write down which columns hold what, using letters.
  3. Paste the prompt on the right with your description in it.
  4. Test the formula on one row you already know the answer to.
Copy this prompt
In Excel, [column letters and what each holds]. I want [what you want to happen] in column [letter]. If there is no match, show [what instead]. Give me the formula only, no explanation. Do not ask me to paste my data.
Five brackets. Covers most lookup and matching jobs.

Four habits with Excel and AI

Five mistakes people really make

1
Filling down before testing
A wrong formula does not error. It gives six hundred plausible wrong answers.
2
Pasting the sheet to "give it context"
Customer names, values and account numbers all leave in one paste.
3
Asking it to calculate instead of writing a formula
The formula is checkable and repeatable. Its arithmetic is neither.
4
Not saying what to do when there is no match
You get #N/A across half the column and assume the formula is broken.
5
Accepting a formula you cannot read at all
You do not need to write it, but you do need to be able to test and describe it.

Formula or macro?

Will I need to do this again next month?
Yes

Ask for a formula

A formula lives in the sheet, updates when the data changes, and anyone can see what it does. Save the prompt that produced it.

No

Ask for steps

For a genuine one-off, the menu steps are faster and leave nothing behind for a colleague to puzzle over later.

What good use looks like

You describe the sheet

Column letters and what each one holds.

It writes the formula

Syntax you never have to memorise.

You test one row

The step that turns a guess into a result.

Two days of matching rows by eye becomes twenty minutes, and the sheet still contains every check a colleague would want to see.

The Excel rule

Describe the sheet. Never paste the sheet. Always test one row.

Those three habits cover every safe use of AI with a spreadsheet.

  • Columns described — safe.
  • Data pasted — a breach.
  • One row tested — trustworthy.

Glossary

Words used in this module

Formula
An instruction Excel calculates itself. Checkable, repeatable and safe.
Lookup
Matching a value in one sheet against a table in another, such as VLOOKUP or XLOOKUP.
#N/A
Excel's way of saying it found no match. Usually a text versus number problem.
One-row test
Checking a formula against a row whose answer you already know, before filling down.
Personal data
Anything identifying a person: a name, a phone number, an account, an employee number.
Prompt
Everything you type in: your column descriptions and what you want to happen.
